
# Base de Datos - Punto de Venta

Proyecto de Programación II.

## Tecnologías
- MySQL 8.0
- Entity Framework Core
- .NET 10

## Base de datos
Nombre: PuntoVentaDB

Contiene 12 tablas:
- Puestos
- Empleados
- Clientes
- Proveedores
- Marcas
- Productos
- Compras
- Compras_Detalle
- Ventas
- Ventas_Detalle
- Usuarios
- Menu

## Instalación
Importar el archivo PuntoVentaDB.sql
utilizando MySQL Workbench.
